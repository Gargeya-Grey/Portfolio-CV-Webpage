# Contact band

## Sub-features
- Inverted band (`--band`: #1b1a18 light, #24221f dark) with the email, a copy button, profile links, and a card to sgargeya.com.
- Footer row with the light mark, name and year, location, and Back to top.

## How to get to it (user POV)
Press "Contact" in the header, or scroll to the end.

## Driving it with the browser pane
- Click the button labelled "Copy email address". Expect the status text "Email copied." (or the fallback message if the pane blocks the clipboard).
- Screenshot the band in light and dark.

## Gotchas
- The clipboard may be denied in the pane; the fallback message is then the correct result, not a failure.
